## 一句话定义

一款竖屏单手休闲街机游戏：障碍与单词由远及近逼近，按序点破字母泡拼完词后，在贴身隐藏时机窗内点跳越过；顺带轻量接触单词释义。（街机玩法为主，轻学习为辅）

## 目标用户

- 主要用户：碎片时间休闲玩家为主（通勤/排队/办公室摸鱼，单局 1–3 分钟）+ 英语学习者为辅
- 不是我们的用户：重度英语学习用户（系统课程/背词计划）；需要复杂多指操作或陀螺仪摇晃的场景；桌面 PC 深度适配（首版以竖屏触控为准）

## 成功标准

仅作设计指引，首版不做数据埋点：

- [ ] ≥70% 首次玩家完成教程并成功越过第一个障碍（含拼完词 + 起跳）
- [ ] 死亡后 1 秒内点「再来一局」的重开率 ≥50%
- [ ] 玩家能在无显式绿窗的情况下凭节奏学会起跳（教程后前 3 障成功率可感知上升）
- [ ] 玩家平均每局看到 ≥5 个单词释义（仓鼠下方常驻释义）

## 范围

### Must Have

- 竖屏向上跑酷：仓鼠在近处，世界/障碍由远及近逼近（透视缩放）
- 单道块状障碍；同屏可有多障，间距开局偏疏；当前目标为最近未越过的一块
- 一词一障；障碍一出现即可点字母；整词字母泡同时出现并随障碍一起逼近
- 按正确顺序点字母泡；点对收入左侧缩小拼成整词；点错当前泡闪红并断 combo
- 长词一行最多 5 泡，超出双行折行（如 8→5+3）
- 拼完词后才可起跳；隐藏时机窗贴仓鼠身前，正式画面不绘制
- 窗内点跳：仓鼠跳到障碍上方越过，过顶后障碍再消失；PERFECT/GOOD 看起跳相对窗中心准度
- 窗外点跳：原地小蹦（空跳），障碍继续逼近；同一障碍仍可再跳救
- 未拼完或未越过而撞上 → 死亡
- 中文释义：当前词在仓鼠下方常驻，越过后切下一词
- 局内变难（本阶段）：只加快逼近速度；间距变密 / 窗变窄等挂词节奏稳定后再定
- 难度 chill / easy / medium / hard 四档（词长分层沿用现库）
- 计分结构沿用：存活 tick + 词分 + 越过分感（含速度倍率 × combo × PERFECT 1.2x）
- 画面风格：绿色清新 + 仓鼠主题；扁平 2D 仓鼠立绘（见冻结视觉原型）
- 障碍皮：现有 4 种 + 同风格再加 6 种（共 10，判定相同）
- 菜单 / 教程 / 游戏 / 暂停 / 结算 / 重开；本地最高分；分享卡片；音效开关
- 音效：点对字母 / 拼完词 / 越过 / combo / 死亡（约 4–6 个）
- 手动暂停 + 切后台自动暂停

### Out of Scope

- 陀螺仪 / 划线双模式（已弃用）
- 桌面端深度适配（原因：竖屏触控优先）
- 数据埋点上报
- 账号 / 在线排行榜
- 系统学习：错词本、复习计划
- 触觉振动
- 成就系统

### Future

- 在线排行榜
- 错词本 / 复习计划
- 更多主题皮肤
- 局内间距加密、隐藏窗收窄等与单词节奏绑定的难度曲线

## 核心用户旅程

| 步骤 | 用户做什么 | 系统做什么 | 成功看起来像 |
|------|-----------|-----------|-------------|
| 1 | 竖屏打开游戏 | 进入菜单 | 标题 + 四档难度 + BEST |
| 2 | 首次点「开始」 | 进入简短教程 | 演示点泡顺序 + 窗内起跳（可无显式绿窗，用文案/手势提示） |
| 3 | 选难度开局 | 生成第一障+词，由远及近 | 整词字母泡出现；释义在仓鼠下方 |
| 4 | 按序点字母泡 | 点对收入左侧；点错闪红断 combo | 左侧拼出完整词 → 可跳 |
| 5 | 障进入贴身隐藏窗时点跳 | 高跳越过，过顶后障消失；结算词分/越过分 | PERFECT!/GOOD + combo |
| 6 | 窗外误点跳 | 原地小蹦，障继续 | 仍可再跳救 |
| 7 | 未拼完/未越过撞上 | 死亡 → 结算页 | 分数/BEST/最佳词/释义回顾 |
| 8 | 点「再来一局」 | 1 秒内重开 | 回到对局 |

## 信息架构 / 主流程

场景列表：

- **Boot**：加载资源
- **Menu**：标题 + 难度（4 档）+ BEST + 开始 + 设置
- **Tutorial**（首次）：点泡 + 起跳教学
- **Game**：对局（暂停按钮 + 切后台暂停）
- **Death**：结算
- **ShareCard**：成绩图

主路径：`Menu → Tutorial（首次）→ Game ⇄ Paused → Death → ShareCard → 重开/回 Menu`

## 体验规格

### 关键界面与状态

- **Menu**：四档难度 + BEST + 开始 + 设置（音效）
- **Tutorial**：短教学，不强制显示绿窗
- **Game HUD**：分数 / 速度倍率 / combo / 暂停
- **字母泡**：肥皂泡造型（非描边圆卡片）；当前应点泡可轻微高亮；整词随障缩放
- **已点字母**：缩小排在泡组左侧，形成「输入完成」感
- **释义条**：仓鼠下方常驻当前词中文
- **隐藏时机窗**：贴仓鼠身前窄带，正式不绘制；调试可用虚线
- **起跳反馈**：窗内 → 跳至障上方再消障；窗外 → 原地小蹦
- **Paused / Death / ShareCard**：同前版框架

### 文案基调

混合：局内 PERFECT! / GOOD / COMBO 用英文；菜单与提示用中文。

### 错误与空态

- 切后台 / 锁屏 → 自动暂停
- 词库打包 JSON，无加载失败态

## 领域细节

### 核心循环

障+词由远及近 → 按序点字母泡拼完词 →（可跳）→ 隐藏窗内点跳越过 → 释义切下一词 → 速度逐渐加快 → 撞死结算。

成功反馈：点对音效；拼完可跳提示；越过 PERFECT/GOOD + combo。

### 胜利 / 失败条件

- 失败：撞上最近障碍（含未拼完、未越过）
- 无尽模式无通关胜利，追高分
- 重试：死亡后「再来一局」1 秒内重开

### 规则清单

- **R1** 竖屏向上：障碍自远处逼近并放大，仓鼠在近处
- **R2** 单道；同屏多障允许，开局间距疏；目标=最近未越过块
- **R3** 一词一障；障出现即可点泡；整词泡同时出现并随障移动
- **R4** 字母必须按拼写顺序点；点错 → 泡闪红 + combo 清零，不推进、不清已拼
- **R5** 点对 → 该泡收入左侧缩小条；收齐 = 可跳
- **R6** 长词：一行最多 5 泡，超出折第二行（保持整词同现）
- **R7** 正式不绘制时机窗；窗贴仓鼠身前；窗外点跳=空蹦（障不消）；窗内且可跳才越过
- **R8** 窗内越过：仓鼠跳到障上方，过顶后障消失；空蹦后同障仍可再跳
- **R9** 未拼完或未越过而撞上 → 死亡
- **R10** 释义在仓鼠下方随当前词常驻，越过切换
- **R11** 本阶段难度递增：只加快逼近速度；间距/窗宽后续再定
- **R12** PERFECT：起跳更接近隐藏窗理想中心 → 1.2x；否则 GOOD
- **R13** 计分 = 存活 tick + 词分（字母数×基础×速度倍率×combo×perfect）+ 越过反馈；结构沿用横屏版 [具体数值待确认]
- **R14** 死亡后 1 秒内可重开；本地按难度存最高分
- **R15** combo：点错清零；死亡清零；成功越过累加

### 状态机

`Menu → Tutorial（首次）→ Playing ⇄ Paused → Death → ShareCard → 重开/回 Menu`

### 进度结构

- 单局无尽
- 现阶段：逼近速度递增
- 词长由所选难度档 + 局内 tier 控制（沿用现库分层思路）

### 输入与手感

- 主输入：单指触控（点泡 / 点跳）
- 不依赖陀螺仪（便于办公室等场景）
- 点跳与点泡独立：先拼完，再在窗内跳
- 同屏多障时操作目标始终是最近一块

### 随机与数值

- 障碍皮在 10 套中随机/轮换，判定一致
- 速度曲线、tick/字母分、窗宽像素值 [待确认]
- 随机种子不固定

### 元系统

- 设置：音效开关（不再含倾斜/划线）
- 音效约 4–6 个
- 本地最高分（按难度）
- 分享卡片
