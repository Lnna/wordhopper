## 一句话定义

一款竖屏单手休闲街机游戏：障碍与单词由远及近逼近，按序点破字母泡拼完词后，在贴身隐藏时机窗内点跳越过；顺带轻量接触单词释义。（街机玩法为主，轻学习为辅）

## 目标用户

- 主要用户：碎片时间休闲玩家为主（通勤/排队/办公室摸鱼，单局 1–3 分钟）+ 英语学习者为辅
- 不是我们的用户：重度英语学习用户（系统课程/背词计划）；需要复杂多指操作或陀螺仪摇晃的场景；桌面 PC 深度适配（首版以竖屏触控为准）

## 成功标准

仅作设计指引，首版不做数据埋点：

- [ ] ≥70% 首次玩家完成教程并成功越过第一个障碍（含拼完词 + 起跳）
- [ ] 死亡后 1 秒内点「再来一局」的重开率 ≥50%
- [ ] 玩家能凭起跳线快速学会起跳时机（教程后前 3 障成功率可感知上升）
- [ ] 玩家平均每局看到 ≥5 个单词释义（仓鼠下方常驻释义）

## 范围

### Must Have

- 竖屏向上跑酷：仓鼠在近处，世界/障碍由远及近逼近（透视缩放）
- 单道块状障碍；**一屏一障**：当前障碍被跳过开始清除时才生成下一个（从远处逼近）；当前目标为最近未越过的一块
- 一词一障；障碍一出现即可点字母；整词字母泡同时出现并随障碍一起逼近
- 按正确顺序点字母泡；点对收入左侧缩小拼成整词；点错当前泡闪红并断 combo；**不提示下一字**（玩家自行从字板找序）
- 长词一行最多 5 泡，超出双行折行（如 8→5+3）
- 拼完词后才可起跳；时机窗位置以横向虚线（起跳线）常显标示，词拼完后线变亮
- 窗口外点仓鼠 = 催促：当前障碍逼近 ×3（已拼完省时为奖励，未拼完增压为惩罚）
- 窗内点跳：仓鼠跳到障碍上方越过，过顶后障碍再消失；PERFECT/GOOD 看起跳相对窗中心准度
- 窗外点跳：原地小蹦（空跳），障碍继续逼近；同一障碍仍可再跳救
- 未拼完或未越过而撞上 → 死亡
- 中文释义：当前词在仓鼠下方常驻，越过后切下一词
- 局内变难（本阶段）：只加快逼近速度；间距变密 / 窗变窄等挂词节奏稳定后再定
- 难度 容易 / 中等 / 困难 三档（单词模式按字母数分层沿用现库；成语模式按词频常见度分层；速度档 0.8x/1.0x/1.2x 两种模式共用）
- 计分结构沿用：存活 tick + 词分 + 越过分感（含速度倍率 × combo × PERFECT 1.2x）
- 画面风格：绿色清新 + 仓鼠主题；扁平 2D 仓鼠立绘（见冻结视觉原型）
- 障碍皮：现有 4 种 + 同风格再加 6 种（共 10，判定相同）
- 菜单 / 教程 / 游戏 / 暂停 / 结算 / 重开；本地最高分；分享卡片；音效开关
- 音效：点对字母 / 拼完词 / 越过 / combo / 死亡（约 4–6 个）
- 手动暂停 + 切后台自动暂停

### Out of Scope

- 陀螺仪 / 划线双模式（已弃用）
- 桌面端深度适配（原因：竖屏触控优先）
- 数据埋点上报
- 账号 / 在线排行榜
- 系统学习：错词本、复习计划
- 触觉振动
- 成就系统

### Future

- 在线排行榜
- 错词本 / 复习计划
- 更多主题皮肤
- 局内间距加密、隐藏窗收窄等与单词节奏绑定的难度曲线

## 核心用户旅程

| 步骤 | 用户做什么 | 系统做什么 | 成功看起来像 |
|------|-----------|-----------|-------------|
| 1 | 竖屏打开游戏 | 进入菜单 | 标题 + 模式 Tab + 三档难度 + 最高分 |
| 2 | 首次点「开始」 | 进入简短教程 | 演示点泡顺序 + 窗内起跳（可无显式绿窗，用文案/手势提示） |
| 3 | 选难度开局 | 生成第一障+词，由远及近 | 整词字母泡出现；释义在仓鼠下方 |
| 4 | 按序点字母泡 | 点对收入左侧；点错闪红断 combo；无下一字提示 | 左侧拼出完整词 → 可跳 |
| 5 | 障接近起跳线时点跳（或点仓鼠） | 高跳越过，过顶后障消失；结算词分/越过分 | PERFECT!/GOOD + combo |
| 6 | 窗外误点空白 | 原地小蹦，障继续 | 仍可再跳救 |
| 6b | 窗口外点仓鼠 | 催促：障碍 3x 加速逼近 | 已拼完=省时；未拼完=增压 |
| 7 | 未拼完/未越过撞上 | 死亡 → 结算页 | 分数/BEST/最佳词 |

## 信息架构 / 主流程

场景列表：

- **Boot**：加载资源
- **Menu**：标题 + 副标题「点字成词 · 时机起跳」+ 模式 Tab（成语 | 单词，**默认成语**）+ 难度（3 档）+ 最高分 + 开始 + 设置
- **Tutorial**（首次）：点泡 + 起跳教学
- **Game**：对局（暂停按钮 + 切后台暂停）
- **Death**：结算
- **ShareCard**：成绩图

主路径：`Menu → Tutorial（首次）→ Game ⇄ Paused → Death → ShareCard → 重开/回 Menu`

## 体验规格

### 关键界面与状态

- **Menu**：模式 Tab（成语 | 单词，默认成语）+ 三档难度（容易/中等/困难）+ 最高分 + 开始 + 设置（音效）
- **Tutorial**：短教学，不强制显示绿窗
- **Game HUD**：分数 / 速度倍率 / combo / 暂停
- **字母泡**（单词模式）：肥皂泡造型（非描边圆卡片）；无「下一泡」高亮；整词随障缩放
- **方框字块**（成语模式）：米白宣纸方框（圆角、绿描边、顶部高光），方方正正贴合汉字审美；无「下一字」高亮；随障缩放
- **已点字母**：缩小排在泡组左侧，形成「输入完成」感
- **释义条**：仓鼠下方常驻当前词中文
- **起跳线**：窗口中心高度的横向虚线，常显（白色半透明）；当前障碍词拼完可跳时变亮（橙色），玩家压线起跳越接近线越易 PERFECT
- **路面滚动**：条纹向屏幕下方滚动（仓鼠向上跑的相对运动，跑步机参照系）
- **起跳反馈**：窗内 → 跳至障上方再消障；窗外 → 原地小蹦
- **Paused / Death / ShareCard**：同前版框架

### 文案基调

全中文：菜单、局内 HUD（分数/速度/连击/完美/不错）、结算页、分享卡片均为中文；仅保留品牌名 Word Hopper。

### 错误与空态

- 切后台 / 锁屏 → 自动暂停
- 词库打包 JSON，无加载失败态

## 领域细节

### 核心循环

障+词由远及近 → 按序点字母泡拼完词 →（可跳，起跳线变亮）→ 障碍近线时点跳越过（或点仓鼠催促加速）→ 释义切下一词 → 速度逐渐加快 → 撞死结算。

成功反馈：点对音效；拼完可跳提示；越过 PERFECT/GOOD + combo。

### 胜利 / 失败条件

- 失败：撞上最近障碍（含未拼完、未越过）
- 无尽模式无通关胜利，追高分
- 重试：死亡后「再来一局」1 秒内重开

### 规则清单

- **R1** 竖屏向上：障碍自远处逼近并放大，仓鼠在近处
- **R2** 单道；一屏一障：当前障碍被跳过开始清除时才生成下一个（progress 0.02 远处），保证每个障碍都有完整逼近时间用于点字；目标=最近未越过块
- **R3** 一词一障；障出现即可点泡；整词泡同时出现并随障移动
- **R4** 字母必须按拼写顺序点；点错 → 泡闪红 + combo 清零，不推进、不清已拼
- **R5** 点对 → 该泡收入左侧缩小条；收齐 = 可跳
- **R6** 长词：一行最多 5 泡，超出折第二行（保持整词同现）
- **R7** 时机窗以起跳线（横向虚线）常显标示；窗贴仓鼠身前；窗外点空白=空蹦（障不消）；窗外点仓鼠=催促加速；窗内且可跳才越过
- **R8** 窗内越过：仓鼠跳到障上方，过顶后障消失；空蹦后同障仍可再跳
- **R9** 未拼完或未越过而撞上 → 死亡
- **R10** 释义在仓鼠下方随当前词常驻，越过切换
- **R11** 本阶段难度递增：只加快逼近速度；间距/窗宽后续再定
- **R12** PERFECT：起跳更接近窗口理想中心（起跳线）→ 1.2x；否则 GOOD
- **R13** 计分 = 存活 tick + 词分（字母数×基础×速度倍率×combo×perfect）+ 催促奖励分（(1-进度)×15×速度倍率，已拼完催促才发，每障碍限一次）+ 越过反馈；结构沿用横屏版 [具体数值待确认]
- **R14** 死亡后 1 秒内可重开；本地按模式 + 难度存最高分
- **R15** combo：点错清零；死亡清零；成功越过累加

## 成语模式（v0.3 新增）

### 入口与难度

- 主菜单标题下「成语 | 单词」模式 Tab；**默认成语模式**，单词为可选
- 两种模式统一三档难度：容易 / 中等 / 困难；速度档 0.8x / 1.0x / 1.2x 共用
- 成语模式难度 = **常见度 + 速度**：按 THUOCL 词频分带（互斥）——容易 ≥2000（约 1200 条，最常见）；中等 1000–1999（约 800 条）；困难 400–999（约 1200 条，较生僻）；接龙与断链回退在所选词频带内进行
- 单词模式难度 = **字母数 + 速度**：容易 3–5 字母；中等 6–8 字母；困难 8+ 字母
- 最高分按模式 + 难度分别存储：`word-hopper-best-{mode}-{difficulty}`

### 玩法规则

- 每个障碍物 8 个汉字**方框字块**（米白宣纸底、圆角、绿描边；非肥皂泡）：上排 4 个、下排 4 个，其中混有一个四字成语；按顺序点对 4 字方可通过
- 其余机制与单词模式一致：逼近/缩放、时机窗（起跳线标示）、窗外空蹦、点仓鼠催促、左右躲避、计分、combo、PERFECT
- 已拼部分沿用「左侧正常文字」：点中后左侧依次显示 `一心` → `一心一意`
- 高亮：当前应点字所在槽位描边高亮；重复字（如「一心一意」两个一）点任意一个均算对，高亮跳到下一个可见槽位
- 释义条常驻显示当前成语释义

### 接龙规则

- 障碍物 N 的成语末字 = 障碍物 N+1 的首字或同音字（**忽略声调**；同字优先于同音字）
- 断链处理：当前末字（含同音）无未用成语可接时，从「高产开头字队列」（按可接成语数量排序取前 100、洗牌后逐个消耗）取字重新起头；队列耗尽则清空已用集合重建
- 一局内同一成语不重复出现

### 数据

- `src/data/idioms.json`：3225 条，每条 `{ t: 成语, p: 去调拼音, m: 释义, d: [4 个干扰字], f: THUOCL 词频 }`
- 过滤口径：四字 + 全部用字在 3500 常用字表内 + THUOCL 词频 ≥400；末字音节可接率 97.6%
- 干扰字：2500 常用字内随机，与该成语 4 字不重复，预生成进库
- 难度词频带：容易 ≥2000 / 中等 1000–1999 / 困难 400–999；各带内部接龙连通性由数据测试校验
- 重新生成：`node scripts/build-idioms.mjs`（确定性输出，原始数据缓存于 `scripts/.cache`，不入库）
